# Skills Dictionary Admin Panel Documentation

## Overview

The **Skills Dictionary Admin Panel** provides a live CRUD user interface for managing skills, detection aliases/patterns, and skill categories within the AI Resume Analyzer platform without requiring codebase edits or redeployments.

---

## Features

- **Live CRUD Management**: Create, view, edit, and delete skills and categories in real time.
- **Pattern Match Engine**: Define comma-separated keyword patterns used by the resume parser engine.
- **Market Demand Score**: Assign relative demand scores (1-100) to influence readiness calculations.
- **Access Control**: Restricted exclusively to users with `admin` or `maintainer` roles.

---

## Usage Guide

1. Navigate to the Admin Dashboard / Skills Dictionary tab.
2. Filter skills by Category or use the Search input to find specific technologies.
3. Click **+ Add New Skill** to introduce a new skill entry.
4. Fill in the Skill Name, Category, Alias Patterns, Description, and Market Demand Score.
5. Click **Save Skill** to apply changes immediately across the platform.
